# Save Selected Files

Добавляет кнопку сохранения в панель действий при выделении файлов. Нажимаете её, и все выбранные файлы сохраняются в «Загрузки» в один клик. Если файл ещё не загружен, плагин докачает его сам. Порт плагина Save Selected Files для exteraGram от [@akresik](https://t.me/akresik).

## Скачать

Готовый файл плагина можно скачать в [Releases](https://github.com/theakres/InuPlugins/releases/tag/save-selected-files).

## Где работает

- Профиль чата, пользователя или канала: вкладки «Медиа» и «Файлы».
- Результаты поиска.
- Настройки → Данные и память → Использование памяти (выделение файлов или целых чатов).

Кнопка появляется в панели действий, которая открывается при выделении, рядом с остальными кнопками (рядом с «Показать в чате» или «Удалить», в кэше рядом с кнопкой очистки).

## Как работает

Плагин хукает три места приложения и добавляет в них кнопку «скачать»:

- `SharedMediaLayout` (конструктор) - профиль;
- `SearchViewPager.showActionMode` - поиск;
- `CacheControlActivity.createView` - использование памяти.

По нажатию:

- **Профиль и поиск.** Выделение закрывается, затем для каждого выбранного сообщения файл (документ или фото) докачивается штатным `FileLoader`, если его нет в кэше. Ожидание длится до 15 минут. Готовый файл копируется в `Загрузки/<название приложения>` через MediaStore под своим именем, фото называются `photo_<id>_<id сообщения>.jpg`.
- **Использование памяти.** Собираются выбранные файлы, а при выборе чатов все файлы этих чатов. Выделение снимается, файлы копируются в «Загрузки» напрямую, тип определяется по расширению.
- По окончании показывается штатная плашка Telegram: «Файл сохранён» или «N файлов сохранено в «Загрузки»», при неудаче - ошибка.

Что-то не получилось сохранить - остальные файлы всё равно сохраняются, а ошибка пишется в лог плагина.

## Гранты

- `unsafe.jvm` - доступ к классам приложения: добавление кнопки в нативную панель, `FileLoader`, запись в «Загрузки» через MediaStore и показ штатной плашки (`BulletinFactory`). Высокоуровневого API для этого нет.
- `unsafe.xposed` - хуки на экраны профиля, поиска и использования памяти.
